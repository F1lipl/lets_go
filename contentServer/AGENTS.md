# 项目协作约定

## 设计与实现优先级

- 本项目面向真实生产环境，架构与代码首先以可上线、可长期运行和可持续演进为目标，不按教学演示项目的标准设计。
- 技术方案优先考虑正确性、一致性、可靠性、可用性、容量、性能、可观测性、可维护性、扩展性、数据生命周期和运行成本。
- 涉及状态变更时，应主动分析并发、幂等、事务边界、失败路径、重试、恢复和数据校准方案。
- 在满足实际需求的前提下体现技术深度；复杂设计必须有明确收益，避免只为展示技术而增加组件。
- 优先参考成熟开源项目和经过实践验证的行业方案。引用其设计时，应说明适用条件、关键取舍以及与当前项目的差异，不能机械照搬。
- 可以给出分阶段落地路径，但必须明确最终生产方案，不能用临时实现掩盖长期架构问题。
